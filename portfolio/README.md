# Anthony Hernandez | Portfolio

Static site: HTML, CSS, vanilla JS, Bootstrap 5 (CDN).

## Run locally
Open `index.html` in a browser (or `python3 -m http.server`).

## Deploy on GitHub Pages
1. Create a repo (e.g. `anthonyh1497.github.io` for a root URL, or any name for `/<repo>` URL).
2. Push these files to the `main` branch.
3. Settings > Pages > Deploy from branch > `main` / root.

## Edit
- Projects: `js/projects.js` (copy an object to add one; empty fields are hidden).
- Thumbnails: put images in `images/` and set `image: "images/name.jpg"`.
- Resume: save your PDF as `assets/Anthony-Hernandez-Resume.pdf`.
- Social links and email: the "Let's connect" section in `index.html`.
